# 重力首页样式预览

这是正式 `/pc` 首页使用的重力球视觉与交互页面。

- 四个满屏章节使用 CSS Scroll Snap 实现滚动吸附。
- 第一屏使用 Matter.js 模拟 36 个图标的重力、碰撞、鼠标排斥和拖拽投掷。
- 图标来自桌面原始 960×960 PNG，仅在本目录生成 256×256 AVIF 轻量副本。
- 36 张原图约 50MB；预览副本合计约 1MB，透明背景保留。
