# 滚轮图标处理规范

请把三张源图各自切成 12 张独立透明 PNG，按从左到右、从上到下编号：

- `reel-1-01.png` ～ `reel-1-12.png`
- `reel-2-01.png` ～ `reel-2-12.png`
- `reel-3-01.png` ～ `reel-3-12.png`

统一要求：

- 画布尺寸：`384 × 384 px`
- 背景：真实透明 Alpha，不保留棋盘格
- 模型完整，不能缺屋顶、树冠、底座、阴影或其他边缘
- 删除相邻格子串入的残片和大范围彩色光晕
- 模型水平、垂直居中，底座中心统一
- 在不裁切的前提下尽量放大，最大边约占画布 `88%`
- 保留模型自身的柔和接触阴影

处理完成后放回本目录即可接入。
