# 附近推荐规则

## 场所范围

定位使用高德坐标校准及逆地理编码。逆地理编码 AOI 范围内或边界 50 米内的场所、地址中明确提及的场所作为当前场所；通过地点名称、地址及父子 POI 关系展开其内部项目。推荐排除整个当前场所。历史地点按同一关系展开，七天内避免重复。不同场所不能仅因类型相同被整体排除。

地图缺少区域或所属关系时不能保证识别完整场所范围。保留原有距离、路线、时间、预算和营业校验；没有合适候选时明确提示，不能编造新地点。

## 产品标签

`apps/api/src/nearby-tags.ts` 是附近地点分类与搜索映射入口。

| 玩法分类 | 地点匹配 | 细分体验 |
| --- | --- | --- |
| games 娱乐玩乐 | 棋牌、桌游、台球、电玩、密室、剧本杀等 | 棋牌桌游、游戏娱乐、沉浸体验 |
| walk 城市散步 | 公园、广场、步行街、步道 | 散步户外 |
| food 美食吃喝 | 餐饮、咖啡、茶饮 | 餐饮吃喝、咖啡茶饮 |
| culture 看展探索 | 博物馆、美术馆、展览馆、科技馆 | 看展文化 |

“放松、探索、热闹”为偏好排序，不能代替地点的玩法分类。“休闲躺平、浪漫约会”为场景入口，可召回多种玩法，不等于单一地点类型。产品标签同时携带室内外、建议基础停留时长、适合心情和同行场景；预算、步行时长、实时营业状态仍从事实校验获得。心情与同行标签是推荐偏好，不是商家承诺。

动物园、海洋馆、游乐园不能仅因供应商标为“风景名胜”而自动归类为散步或看展。运动、演出等后续增加独立分类前，不混入现有四类。

## 数据来源

目前线上附近推荐仍使用高德，并未接入大众点评或美团。将来授权接入其他供应商时，先转换为统一地点模型，再经过相同产品分类、场所关系及事实校验；不同供应商的 ID 不能直接比较，需要单独维护地点关联。图片、价格、营业信息保留供应商来源，未知信息不能自动补为真实值。
