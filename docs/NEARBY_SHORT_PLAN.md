# 现在出发，玩 1–3 小时

沿用 Expo Web / Express / 高德 Web 服务 / 现有模型 / ECS；不创建新付费资源。

## 本轮流程

手机或电脑 Web 在“旅行抽取”页面单独发起附近小行程：选择可用时间、人均预算、人数、玩法类型、步行上限和心情。每次生成先获取新的 GPS 坐标，服务端校准为高德坐标、核实城市、查询实时 POI、当前天气、双方向步行路线和平台今日营业时段。只安排一个主要活动，含往返与十分钟缓冲，最多核查两个候选，最多一次限时模型请求。

地址、图片、价格、开闭时段和交通时间只能来自高德。AI 只选择给定候选并建议互动玩法；模型输出经过 ID、时长、营业窗口和事实字段边界检查。失败时标记基础攻略，不伪装 AI 生成。未知价格或营业信息默认不通过；用户明确选择包含待确认地点后才生成带醒目标注的条件方案。参考人均消费不等于实时报价，预约、排队和席位均需另确认。

照片只显示 API 中同一 POI 的高德相关来源链接，保留来源入口，不用别处城市图冒充；无照片时使用中性占位。

## 接口

`POST /api/v1/nearby/plan`，JSON 请求：latitude / longitude / coordinateSystem（wgs84 默认）/ locationTimestamp / accuracyMeters / availableMinutes（60,120,180）/ maxWalkMinutes（10,20,30）/ budgetPerPersonYuan / partySize / mood / kind / allowUnverified / excludePoiIds。

返回 ready、conditional 或 no_match。包含行程时间线、真实地点、预算说明、数据来源、核验状态、AI 或基础规则生成标识。定位超过五分钟或精度低于一千米拒绝生成；无有效城市或交通数据不伪造距离。生成时间戳与十分钟有效期随结果显示。前端条件变更清除旧结果；错误后可重试；换地点排除已看过的 POI。

## 验收

- 北京/上海不串城，WGS84 坐标必须校准后用于路线。
- 预算不足、时间不足、闭馆、天气不适合及路线查询失败均不产生无依据的可执行方案。
- 未知费用、未知营业、过期天气默认拒绝；用户明确接受待确认项才可条件展示。
- 时间线含往返与缓冲且总时长不超过选择范围；跨午夜、午休和临近关门有回归用例。
- 模型输出无效 ID、过长停留或价格/营业承诺时回退基础规则并说明。
- 真正的实时 API / 模型验收与离线 mock 测试分别记录；手机 GPS 权限需用户真机确认。
